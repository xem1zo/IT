## Docker — практические задания

Эта директория содержит практические работы по теме **Docker** для курса из репозитория `IT`.

### Навигация по заданиям

- **Welcome to Docker** — первое знакомство с контейнерами, запуск тестового образа и базовые команды внутри контейнера.  
  - Описание и скриншоты: [`WelcomeToDocker/README.md`](./WelcomeToDocker/README.md)

### Как пользоваться

1. Перейдите в нужное подзадание (например, в `WelcomeToDocker`).
2. Откройте соответствующий `README.md` и следуйте шагам.
3. Делайте скриншоты по ходу выполнения и складывайте их в папку `img` (для задания `Welcome to Docker` — в `Docker/img`).
4. Ссылку на конкретный `README.md` в GitHub можно отправлять преподавателю как отчёт по работе.
