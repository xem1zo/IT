## 1️⃣ Клонирование репозитория

```shell
git clone https://github.com/drawdb-io/drawdb
```

```shell
cd drawdb/
```


---

## 2️⃣ Запуск проекта

```shell
docker compose up -d
```

Проверка запуска:

```shell
docker compose ls
```
