# Repository Sync Tool

Автоматизированный скрипт для синхронизации локального репозитория с удаленным и последующего копирования содержимого в другой локальный репозиторий.

## ⚠️ ВАЖНО ПЕРЕД ЗАПУСКОМ

1.  **ОТРЕДАКТИРУЙТЕ ПУТИ:** Откройте файл скрипта (`sync.sh` или `sync.ps1`) и замените пути-заглушки на реальные пути к вашим папкам.
    *   Найдите строки `SOURCE_DIR` и `DEST_DIR`.
    *   Впишите туда полные пути без пробелов и кириллицы.
2.  **БЕЗОПАСНОСТЬ:** Скрипт заменяет файлы в целевой папке. Убедитесь, что `DEST_DIR` указывает именно на тот репозиторий, который вы хотите обновить.
3.  **.GIT ПАПКА:** Скрипт автоматически игнорирует папку `.git` при копировании, чтобы не сломать историю второго репозитория.

## Как использовать

### Linux / macOS
1. Откройте терминал в папке со скриптом.
2. Дайте права на выполнение: `chmod +x sync.sh`
3. Запустите: `./sync.sh`

### Windows
1. Нажмите правой кнопкой мыши на файл `sync.ps1`.
2. Выберите "Run with PowerShell" (Запустить с PowerShell).
   *Если появится ошибка политики выполнения, введите в терминале перед запуском:* `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`

## Настройка Push (опционально)
Внутри скрипта есть переменная `ENABLE_PUSH` (или `$enablePush`).
*   Установите значение `true` (или `$true`), если нужно автоматически отправлять изменения в удаленный репозиторий назначения.
*   По умолчанию стоит `false` (безопасный режим).
