# Синхронизация репозитория

Скрипт для синхронизации локального репозитория с удаленным и последующего копирования содержимого в другой локальный репозиторий.

1.  **Пути:** Перед запуском внимательно проверьте переменные `SOURCE_DIR` и `DEST_DIR` внутри скрипта. Ошибка в пути может привести к перезаписи важных данных.
2.  **Имена файлов:** Не используйте пробелы, кириллицу и спецсимволы в именах файлов и папок репозиториев.

---

## Требования
- Установленный **Git**.
- Для Bash версии: утилита `rsync` (обычно предустановлена в Linux/macOS).
- Для PowerShell версии: Windows 10/11 (Robocopy встроен в систему).

## Настройка
1.  Откройте файл скрипта (`migrate_git.sh` или `migrate_powershell.ps1`) в текстовом редакторе.
2.  Найдите секцию **Настройки**.
3.  Замените пути-заглушки на реальные пути к вашим папкам.
    - `SOURCE_DIR`: Путь к репозиторию, откуда тянем обновления (`git pull`).
    - `DEST_DIR`: Путь к репозиторию, куда копируем файлы.

---

# Запуск

## Bash

### 1. Задаем права:
 - chmod +x migrate_git.sh

### 2. Активируем скрипт:
 - ./migrate_git.sh

## PowerShell 

### 1. Задаем права:
 - Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

### 2. Активируем скрипт:
 - .\migrate_powershell.ps1
