# Основы редактирования текста

## Курсор
- `Home` - в начало строки
- `End` - в конец строки
- `PgUp` - в начало документа
- `PgDown` - в конец документа

- `Ctrl+>` перемещение курсора по словам вправо
- `Ctrl+<` перемещение курсора по словам влево

## Сохранение

- `Ctrl+S` - сохранение всего документа
- `Ctrl+Z` - отмена последнего действия
- `Ctrl+Y` - возврат последнего действия

## Выделение

- `Ctrl+A` - выделить всё
- `Ctrl+>` - выделение по символу вправо
- `Ctrl+<` - выделение по символу влево
- `Shift+^` - выделение строк вверх
- `Shift+v` - выделение строк вниз

## Многострочное редактирование

- `Ctrl+Shift+\` - вертикальное ведение вверх
- `Ctrl+Shift+v` - вертикальное ведение вверх

## Табуляция

`Tab` - отступ на 2 или 4 пробела
