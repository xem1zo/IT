## Скриншоты для отчёта по Apache

Положите сюда ваши скриншоты (PNG/JPG) с **точно такими именами**, как указано в файле:

- `/content/Docker/ImageLibrary/Apache.md`

### Важно про отображение

Некоторые просмотрщики Markdown (и иногда GitHub в зависимости от контекста) могут **не показывать SVG**.
Поэтому в `Apache.md` сейчас стоят **PNG‑плейсхолдеры по ссылкам** (placehold.co), чтобы картинки отображались гарантированно.

Когда сделаете настоящие скриншоты:

- сохраните их в эту папку (PNG/JPG)
- замените ссылки в `Apache.md` на локальные пути вида `img/apache/<имя>.png`
